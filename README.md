# AI Developer Orchestrator V3

A local Python-based AI development team orchestrator.

Purpose:
- Run the AI development team on a laptop.
- Use a local Git checkout as the working copy.
- Use Git/GitHub CLI for source control and PR workflow.
- Use an OpenAI model as the reasoning engine.
- Keep secrets outside the repository.
- Start read-only by default.

This is an execution scaffold, not an autonomous production deployment system.
Human approval remains required for destructive or production actions.
