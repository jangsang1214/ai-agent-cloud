# Changelog

## v0.2 — computed engine foundation

- Replaced hand-entered strategy scores with indicator-driven calculations.
- Added SMA, RSI, ATR, realized volatility, volume ratio, relative strength and 25-day deviation percentile.
- Added market-regime scoring and strategy routing.
- Added ATR-derived entry, invalidation and target bands.
- Added DEMO ↔ LIVE technical mode.
- Added secure Massive server adapter and `/api/bars` endpoint.
- Added `/api/universe` and `/api/grouped` foundations for full U.S. market scanning.
- Added tests and GitHub Actions CI.
- Added point-in-time and anti-overfitting design rules.

## v0.1 — interactive prototype

- Rebuilt the repository as ATLAS Trading OS.
